# ありがとうカウンター

「ありがとう」と声で言うと数が増える PWA。目標は 50 万回で、1 万回ごとに花が 1 輪咲きます（全 50 輪）。

## できること

- 声でカウント（Web Speech API）、タップで +1
- 節目のお祝い：100 回ごと（ひとこと）、100・500・1,000 回（特別）、1,000 回ごと（メダルのお知らせ）、1 万回ごと（花が咲く）、10 万回ごと（花の輪）、50 万回（奇跡の満開）
- 花ごとに「自分へのごほうび」メモ（咲く前から決めておける）
- 今日の回数・合計・直近 1 週間のグラフ
- ひとつ戻す（まとめて足した分も 1 回で戻る）、まとめて足す
- バックアップ／復元（JSON ファイル、または文字のコピー＆貼りつけ）
- リセット（数をゼロに戻す。ごほうびメモは残すか選べる。直前の記録を 1 つ取っておき「リセット前に戻す」で戻せる）
- ホーム画面に追加、オフライン動作

## ファイル構成

| パス | 役割 |
| --- | --- |
| `index.html` / `styles.css` | 画面 |
| `help.html` | 使い方の説明書（アプリの「？」から開く。オフラインでも読める） |
| `js/store.js` | 記録の保存・足す・戻す・復元時の検証 |
| `js/milestones.js` | 節目（100ごと/100・500・1000/1000ごと/花/10万ごと/50万）の判定 |
| `js/flowers.js` | 50 輪の花の名前と SVG |
| `js/speech.js` | 音声認識 |
| `js/chart.js` | 週グラフ |
| `js/celebrate.js` | お祝い演出・音・振動・トースト |
| `js/main.js` | 画面の配線 |
| `sw.js` / `manifest.webmanifest` | PWA |
| `tools/make-icons.py` | アイコン生成（Pillow）。`python3 tools/make-icons.py` で「芽吹く一輪」を出力。`--preview <dir>` で全案の比較画像 |

記録はブラウザの localStorage（キー `arigato-counter/v2`）に保存されます。`reference/` の旧版のデータ（`arigato-counter-v1`）があれば自動で引き継ぎます。

## 手元で動かす

```bash
python3 -m http.server 8765
```

http://localhost:8765 を開きます。localhost では Service Worker を登録しません（キャッシュで更新が見えなくなるのを防ぐため）。オフライン動作を確かめるときは `http://localhost:8765/?sw` を開きます。

テスト:

```bash
npm test
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリ（例: `arigato-counter`）を作る
2. このフォルダの中身を push する（`reference/` は除外しても可）
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/arigato-counter/` で公開されます

パスはすべて相対パスなので、サブディレクトリでもそのまま動きます。

### 更新を配るとき

`sw.js` の `VERSION`（例: `'v1'` → `'v2'`）を上げてから push してください。上げないと、インストール済みの端末には古いファイルが表示され続けます。ファイルを追加したときは `APP_FILES` にも追記します。

利用者がアプリを開いたり戻ってきたりすると新しい版を確かめ、届いていれば自動で再読み込みします（声で数えている最中・ダイアログ表示中・お祝い表示中は、終わるかアプリを離れるまで待ちます）。

## 端末ごとの注意

- **音声認識はネット接続が必要**です（Chrome・Safari とも、音声をサーバーで認識するため）。オフラインのときはタップで数えてください。
- **iPhone**: Safari で開いて「共有 → ホーム画面に追加」。iOS のバージョンによっては、ホーム画面から開いたときに音声認識が動かないことがあります。その場合は Safari のタブで使ってください。
- **Android**: Chrome で開くと「アプリをインストール」が出ます。
- マイクの許可を求められたら「許可」を選んでください。
- 記録は端末の中だけにあります。機種変更の前にバックアップを保存してください。
